## 🏷️ White-Label & Re-Branding Instructions for Buyer

Buyers can rebrand the entire system in under **30 minutes**:

1. **App Name & Branding**:
   - Replace `"CamAI"` in `desktop/package.json`, `mobile/package.json`, and `portal/package.json`.
2. **Logos & Graphics**:
   - Swap `build/icon.ico` (Desktop), `android/app/src/main/res/drawable/` (Mobile), and `portal/public/logo.svg` (Portal).
3. **Database & API Keys**:
   - Update `.env` with buyer's Supabase Project URL & Anon/Service Keys.
4. **Build & Package**:
   - Desktop Installer: `cd desktop && npm run build`
   - Mobile APK: `cd mobile && npm run build:apk`
