🌐 Web SaaS Portal & Cloud Backend (`portal/` & `supabase/`)

The Cloud SaaS portal is the central administrative interface for managing organizations, camera fleets, license keys, user roles, and alert notifications.

  • ✓
    Multi-Tenant Isolation: PostgreSQL Row Level Security (RLS) ensures absolute data privacy across organizations.
  • ✓
    Camera Management: Web-based zone creation, line crossing rules, and sensitivity thresholds.
  • ✓
    Supabase Edge Functions: Auto-dispatching Telegram, SMS, and email alerts on AI intrusion events.
// portal/src/lib/supabaseClient.ts import { createClient } from '@supabase/supabase-js'; export const supabase = createClient( import.meta.env.VITE_SUPABASE_URL, import.meta.env.VITE_SUPABASE_ANON_KEY ); // Realtime Camera Config & Alert Synchronization supabase .channel('camera-changes') .on('postgres_changes', { event: '*', schema: 'public', table: 'cameras' }, payload => { console.log('Realtime Camera Config Updated:', payload.new); }) .subscribe();

🖥️ Windows Desktop Client (`desktop/`)

Supervises the local FastAPI engine, manages encrypted DPAPI device binding, auto-discovers network cameras, and renders high-FPS grid views.

  • ✓
    DPAPI Hardware Binding: Encrypts tokens using Windows MachineGUID, CPU ID, and TPM serials.
  • ✓
    Zero-Latency Grid: 30-40 FPS MJPEG preview stream with decoupled background AI inference.
  • ✓
    Camera Sync Engine: Auto-reconciles cloud camera rules with local engine endpoints.
// desktop/src/lib/localEngine.ts export async function syncCamerasToLocalEngine(cameras: any[]) { const status = await getEngineAppStatus(); if (!status) return; for (const cam of cameras) { await fetch(`${ENGINE_BASE}/api/cameras/${cam.id}/config`, { method: 'POST', headers: await controlHeaders(), body: JSON.stringify({ zones: cam.zones, lines: cam.lines, zone_profile: cam.zone_profile }) }); } }

📱 Mobile Application (`mobile/`)

Provides real-time mobile push notifications, live RTSP stream playback with bounding boxes, and mobile camera RTSP streaming.

  • ✓
    Instant Push Alerts: Telegram & Webhook push notifications with event snapshot images.
  • ✓
    Live Mobile RTSP Stream: Turns mobile camera into an IP camera for CamAI edge detection.
  • ✓
    Zero-App Browser View: Live video viewer with bounding boxes in mobile web browser.

📹 AXIS ACAP Native Edge Application (`ACAP/`)

A C/C++ native application compiled for AXIS network cameras. Executes 100% on-device AI analytics using hardware NPU DLPU accelerators.

  • ✓
    AXIS VDO API (`vdo-stream.h`): Zero-copy frame buffer acquisition directly from camera ISP.
  • ✓
    AXIS Larod API (`larod.h`): Hardware NPU acceleration for YOLOX-Tiny ONNX model.
  • ✓
    AXIS axevent & axoverlay: Native ONVIF event publishing and hardware stream bounding box rendering.
  • ✓
    ByteTrack C++ Tracker: Kalman Filter state vector + Hungarian matching algorithm for 0 ID switches.
