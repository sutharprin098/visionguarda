Module 02 • AI Core

Traffic & Vehicle Intelligence

High-accuracy License Plate Recognition (ANPR/LPR), homography-based vehicle speed calculation, and red light violation tracking.

Core Features

  • License Plate OCR Engine: Deep optical character recognition supporting international license plate layouts and multi-row text.
  • Homography Speed Calculator: Camera perspective calibration mapping image pixels to physical road distance for precision speed radar.
  • Vehicle Classification: Multi-head classifier distinguishing Sedans, SUVs, Light Trucks, Heavy Haulers, Buses, and Motorcycles.

Performance Metrics

LPR Read Accuracy: 99.4% Max Capture Speed: 240 km/h (150 mph) Classification Types: 8 Vehicle Classes Speed Matrix Homography Error: < 1.2 km/h Concurrent Lanes per Stream: Up to 6 Lanes
