Module 01 • AI Core

Security & Perimeter Defense

Real-time autonomous perimeter protection featuring virtual tripwires, polygon intrusion detection, loitering metrics, and directional vectoring.

Core Capabilities

  • Virtual Tripwire Line Crossing: Detect vehicles or pedestrians crossing user-drawn vector lines in specified direction.
  • Polygon Intrusion Zones: Define arbitrary multi-point geometric zones with immediate intrusion trigger alerts.
  • Loitering Time Threshold: Monitor object dwell time inside restricted areas; trigger alarm upon exceeding dynamic time limits.
  • Directional Vector Tracking: Optical vector analysis ensuring objects moving in approved directions do not generate false positives.

Model Architecture Specs

Primary Model: YOLOv8x-Perimeter Backbone: CSPDarknet53 Frame Processing Latency: 8.4ms @ 1080p Min Target Size: 16x16 pixels False Positive Rate: < 0.02% Hardware Acceleration: TensorRT FP16 / ACAP Edge VPU
