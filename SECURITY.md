# CamAI Enterprise - Security Policy

---

## Reporting Vulnerabilities

If you discover a security vulnerability in CamAI Enterprise, please report it via encrypted email to:
`security@camai.enterprise.com`

---

## Security Standards Implemented

- **JWT Authentication**: Secured Bearer tokens.
- **RBAC**: Strict role gating (`Admin`, `Operator`, `Viewer`).
- **Encrypted RTSP Credentials**: AES-256 encrypted database columns.
- **Audit Trails**: Non-repudiable audit logging for all user management and evidence export operations.
